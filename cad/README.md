# Project CAD files

Native models, neutral exports and CAD drawings for [Vinamra Jain’s mechanical design portfolio](https://vinamra2101.github.io/).

| Project | Files | Contents |
| --- | ---: | --- |
| [NASA SPEED](./nasa-speed/) | 39 | Fusion concept, assembly and motion studies, STEP assemblies and parts, and DXF drawings |
| [NASA Moon Movers](./moon-movers/) | 2 | Current Revision D Fusion assembly and STEP export |
| [Hydraulic Scissor Lift](./hydraulic-scissor-lift/) | 2 | Native Fusion assembly with centre pivot hardware and STEP export |

Open `.f3d` files in Autodesk Fusion. The `.step` files contain exchange geometry. The `.dxf` files contain editable drawing linework.

The [University Projects](https://vinamra2101.github.io/work/university/) page presents the milling jig assembly drawing, credited to Vinamra and Ziyi, and the boring bracket modelling study. The [dental implant case study](https://vinamra2101.github.io/work/dental/) presents the published research figures.

Web viewer models are available for [SPEED](../assets/speed-cad.glb), [Moon Movers](../assets/moon-cad.glb) and the [scissor lift](../assets/scissor-cad.glb).

The library contains 43 CAD files.
