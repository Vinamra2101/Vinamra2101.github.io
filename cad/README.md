# Project CAD files

Native models, neutral exports and CAD drawings for [Vinamra Jain’s mechanical design portfolio](https://vinamra2101.github.io/).

| Project | Files | Contents |
| --- | ---: | --- |
| [NASA SPEED](./nasa-speed/) | 39 | Fusion concept, assembly and motion studies, STEP assemblies and parts, and DXF drawings |
| [NASA Moon Movers](./moon-movers/) | 2 | Current Revision D Fusion assembly and STEP export |
| [Hydraulic Scissor Lift](./hydraulic-scissor-lift/) | 13 | Native Fusion assembly with centre pivot hardware, STEP assembly, and the supplied SolidWorks reference and recovered solids |
| [Milling Jig](./milling-jig/) | 19 | SolidWorks reference assembly and parts, editable DXF sheets, and converted STEP and STL files |
| [Boring Bracket](./boring-bracket/) | 2 | KTH course-provided Parasolid part and stock |
| [Product Development of Dental Implants](https://vinamra2101.github.io/work/dental/) | | The supplied research materials contain published CAD figures and analysis results. Editable model files were unavailable. |

Open `.f3d` files in Autodesk Fusion. The `.step` files contain exchange geometry. The `.dxf` files contain editable drawing linework. Open each SolidWorks assembly with its companion parts in the same folder.

## Model provenance

- The Moon Movers and scissor lift models match the published interactive views. The original SolidWorks inputs to the scissor lift rebuild are identified as reference files.
- The milling jig drawing shown in the portfolio credits Vinamra and Ziyi. The supplied SolidWorks assembly is the reference for the CAD conversions. The set screw STEP contains surface geometry, and the clamping ring and assembly STL files are display meshes.
- The boring bracket part and stock came from the KTH CAM course materials.
- Web viewer models are also available in the site assets for [SPEED](../assets/speed-cad.glb), [Moon Movers](../assets/moon-cad.glb) and the [scissor lift](../assets/scissor-cad.glb).

The library contains 75 CAD files.
